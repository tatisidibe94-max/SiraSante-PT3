# SiraSanté — Projet Tutoré 3

## Description

SiraSanté est un système d'information destiné au CSCOM Benkadi.

Ce projet est réalisé dans le cadre du module Projet Tutoré 3 en Licence 3 Génie Logiciel.

## Modules du projet

Le système comprend les modules suivants :

- M1 : Authentification et rôles
- M2 : Dossier patient
- M3 : Consultations
- M4 : Pharmacie et stock
- M5 : Caisse
- M6 : Rapports et tableau de bord
- M7 : Rappels SMS

## Prototype obligatoire

Les modules obligatoires du prototype sont :

- M1 : Authentification et rôles
- M2 : Dossier patient
- M5 : Caisse
